# EKO-RED
Codigo usado en el proyecto de IOT EKO-RED
En que consiste?.
es un sistema de monitoreo basico de estandares ambientales.
toma datos como temperatura, humedad y valores de co2 en el ambiente.
todos estos datos, se envian a un apartado de dashboard en nodered para ver los datos en tiempo real y sus fluctuaciones
sumado a que, al integrar una pantalla oled, podremos ver los datos que analiza de modo fisico y tangible en caso de que no tengamos un apartado con nodered a nuestro alcance, donde mostrara a traves de distintas pantallas el analisis de parametros, y en caso de mostrar anomalias, lanzará una alarma.

proyecto util para: Entornos de baja o nula seguridad.
publico objetivo: cualquiera.
